# portfolio-site

Oren's portfolio site — https://portfolio.oedinger.stream (Python server on
the Raspberry Pi, behind Cloudflare Access).

## Pages

- `/` — מצב התיק (positions overview)
- `/positions` — פירוט פוזיציות
- `/signals` — אותות
- `/garp` — GARP ושיטה
- `/daily` — סיכום יומי
- `/house` — רכישת בית (available cash for a house purchase: vested Meta
  RSU net after tax × slider, investment portfolio net after loans
  excluding Norton, current home net proceeds; purchase cost, mortgage
  mix and an optional bridge-loan simulation from the Planit reports)

## Files

- `server.py` — the whole site (single-file Python server).
- `seed.json` — positions seed data read at startup.
- `garp-manifest.json` — GARP chart manifest read at startup.

## Not in this repo

- `charts/` — GARP chart PNGs served by the site. Binary, generated by
  the GARP pipeline; they live on the Pi only (the snapshot-push tool
  handles text files only).

- `digest/` — daily Flex digest data, regenerated every 6h by the
  pipeline (runtime data, not code).
- `server.log`, `__pycache__/`, `*.bak-*` — logs, bytecode, backups.

## Deploy

Copy the snapshot to `~/portfolio-pi/` on the Pi and restart the server
process (`python3 server.py`, no systemd — see AGENTS.md for the restart
procedure). Data source: IB Flex pulls twice daily (23:15 + 08:00 IST).

## Workflow (Pi)

All GitHub work for this repo runs from the Pi: edit in ~/github/portfolio-site, commit and push with git over SSH (pi-backup key). Pushes from the Pi need no Muse approval card.
